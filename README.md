# 3D-building-model-RPG
## Overview
Explore a 3D building model through an interactive, first-person tour. Move through the model as you would in a first-person shooter game, observe its features, and compare them with the 2D drawings to answer the 20 questions in the corresponding quiz.

## Requirements
- The entire 3D model tour ZIP file of this repository
- A personal computer that can run ARCH MODEL TOUR.exe

## Installation and Launch
1. Download the 3D model tour ZIP file to your computer.
2. Extract the ZIP file into a folder saved locally on your computer.
3. Open the extracted folder and double-click ARCH MODEL TOUR.exe.
4. The application opens in full-screen mode. To switch between the application and other windows, use the Windows logo key (or the Command key on a Mac).
5. To exit, close the application window. You can access the menu by pressing the Windows key (or Command on a Mac), or open Task Manager with Ctrl + Alt + Del and select the application to end.

## Controls
- Look around: Move the mouse.
- Move through the model: Use the arrow keys. Movement is relative to the direction you are facing.
- Access spaces: The building’s walls are passable.

## Caution
- Gravity applies, so you may fall if you are not standing on a horizontal surface.
- If you go beyond the site boundaries, you will become trapped in a continuous falling loop. Exit the application to stop it.
